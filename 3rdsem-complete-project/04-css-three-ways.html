04. Three Ways to Add CSS

Compare Inline, Internal, and External stylesheets side-by-side:

1. Inline CSS (style="...")

Applied directly on this <div> tag. Highest specificity, but difficult to maintain or reuse.

2. Internal CSS (<style> in <head>)

Styled using the .internal-card class inside this file's <head> section.

3. External CSS (04-external.css via <link rel="stylesheet">)

Industry Best Practice! Loaded from 04-external.css so one file can style hundreds of pages.
