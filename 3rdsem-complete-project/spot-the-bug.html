🐞 Spot the Bug! (Day 1 Debugging Lab)

Ask students to identify the bug in each snippet, then click Reveal Fix:

Bug #1: Flexbox Not Working 
.navbar {
  justify-content: space-between;
  align-items: center;
}
Fix: Added display: flex;! Alignment properties do nothing unless flex display is enabled.
Bug #2: 100% Width Overflow 
.card {
  width: 100%;
  padding: 32px;
  border: 4px solid white;
}
Fix: Added box-sizing: border-box; so padding & border stay inside the 100% width!
Bug #3: Stylesheet Not Loading 
<head>
  <link src="04-external.css">
</head>
Fix: Use <link rel="stylesheet" href="04-external.css"> instead of src!
Bug #4: Specificity Override 
#hero { color: purple; }
.yellow { color: yellow; }
Fix: Use #hero.yellow { color: yellow; } because ID (0,1,0,0) beats Class (0,0,1,0).
