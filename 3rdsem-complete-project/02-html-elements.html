02. Common HTML5 Elements Reference

Essential building blocks used in modern semantic webpages:

1. Headings & Inline Text Semantics

Use <strong> for strong importance, <em> for stress emphasis, <mark> to highlight key terms, <code> for inline code, and Ctrl + S (<kbd>) for keyboard shortcuts.

"Semantic HTML gives meaning to web structure for both browsers and screen readers." — MDN Web Docs

2. Ordered (<ol>) & Unordered (<ul>) Lists

Unordered List (Bullets):
  • <header> & <nav>
  • <main> & <section>
  • <footer>
Ordered List (Numbered):
  1. Plan HTML structure
  2. Style with CSS rules
  3. Add interactivity with JS

3. Structured Data Tables & Native Accordion

ElementRoleDefault Display
<div> / <section>Block-level containerblock
<span> / <a>Inline text wrapper / hyperlinkinline
<img> / <button>Embedded media / interactive controlinline-block
💡 Click to expand native HTML5 <details> & <summary> accordion (Zero JS!)

The <details> element creates a native disclosure widget that users can open and close without a single line of JavaScript.
